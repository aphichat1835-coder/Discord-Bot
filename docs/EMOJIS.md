# คู่มือและการจัดการอิโมจิของระบบ (System Emoji Catalog & Reference)

เอกสารนี้รวบรวมรายการอิโมจิทั้งหมดที่ใช้งานในระบบบอท รวมถึง **อิโมจิต้นแบบ (Prototype / Unicode Fallback)** และ **คำอธิบายหน้าที่การใช้งาน** เพื่อให้ผู้ดูแลระบบและนักพัฒนาเข้าใจความหมายและนำไปปรับแต่งได้อย่างถูกต้อง

---

## 1. การกำหนดค่าในระบบ (`discord/config.json`)

ในไฟล์ [`discord/config.json`](file:///workspaces/discordbot4/discord/config.json) ได้จัดโครงสร้างให้อิโมจิดิสคอร์ดที่ใช้งานจริงและอิโมจิต้นแบบพร้อมคำอธิบาย **อยู่แนบข้างกันในบรรทัดเดียวกัน (Side-by-Side on the same line)**:
- **คีย์หลัก (เช่น `"universe"`):** กำหนดค่าเป็น Custom Emoji ของ Discord (`<a:Light_pmt:...>`) ซึ่งโค้ดของบอทจะเรียกใช้อิโมจิตัวนี้โดยตรง
- **Companion Key (เช่น `"_universe"`):** แนบอยู่ข้างกันในบรรทัดเดียวกัน ระบุทั้งอิโมจิต้นแบบ Unicode และคำอธิบายหน้าที่การใช้งาน เพื่อให้ผู้พัฒนาหรือผู้ดูแลระบบที่เปิดดูเข้าใจได้ทันที โดยไม่รบกวนการทำงานของ Discord.js

## 4. ข้อควรระวังในการพัฒนา (Developer Notes)

1. **ขีดจำกัดความยาว Label บน Modal (45 ตัวอักษร):** 
   - Discord API มีข้อกำหนดว่า Text Input Label บน Modal ต้องมีความยาวไม่เกิน 45 ตัวอักษร
   - หากใช้ Custom Emoji รูปแบบ `<:name:id>` เช่น `<:Discord_pmt:1553835220912840814>` ซึ่งมีความยาวประมาณ 33-35 ตัวอักษร ให้ใช้ฟังก์ชันช่วย `formatModalInputLabel` ใน [`discord/commands/panelViews.js`](file:///workspaces/discordbot4/discord/commands/panelViews.js) เพื่อป้องกันไม่ให้ความยาวรวมของ Label เกินขีดจำกัด
2. **การเรียกใช้งานในโค้ด:**
   - เรียกใช้งานผ่าน `config.emojis.<key>` เสมอ
   - กรณีที่ต้องการ Fallback เป็นอิโมจิต้นแบบ สามารถใช้ `config.emojis.<key> || config.default_emojis?.[<key>]` ได้อย่างปลอดภัย
