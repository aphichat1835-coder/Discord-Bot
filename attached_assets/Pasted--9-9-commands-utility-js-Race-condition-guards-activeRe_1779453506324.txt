Bug X-1: ❗ Voice Worker console.log wrapper ชนกับ index.js wrapper
ลำดับ require:
index.js ครอบ console.log → push เข้า webLogs
index.js require('./voiceWorker') → voiceWorker.js ทำงาน
voiceWorker.js console.log = (...args) => {...} ครอบทับอีกชั้น
ตอน console.log(...) ถูกเรียก:
voiceWorker wrapper ทำงาน → call _origLog (= index wrapper)
index wrapper → push webLogs → call originalLog (= native)
ปัญหา: ถ้าใครเรียก console.log ก่อน voiceWorker require → ใช้ index wrapper ตรงๆ → ไม่ทริก voice log
ผลกระทบจริง:
ทุก log ที่มาจาก voiceWorker ผ่าน 3 layers
Performance penalty นิดหน่อย
ถ้า voice log pattern match fail → ลอยเฉยๆ ไม่กระทบระบบ
🩹 แก้: ใช้ EventEmitter pattern แทน console wrapper:
// voiceWorker.js
const { EventEmitter } = require('events');
const voiceEvents = new EventEmitter();
exports.voiceEvents = voiceEvents;
// แทน console.log + match string → emit:
voiceEvents.emit('connect', { sessionId, detail: 'Voice connected' });
// index.js:
voiceWorker.voiceEvents.on('connect', ({sessionId, detail}) => pushVoiceLog('connect', sessionId, detail));
