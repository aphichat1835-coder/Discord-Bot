Security / Policy

ตั้งค่าเงื่อนไขการยืนยันตัวตนและการกรองความเสี่ยง
Policy
Block VPN / Proxy / TOR
กันบัญชีที่ตรวจพบว่าใช้ VPN, Proxy, TOR หรือ Hosting network
Require Email
ต้องมี email ในบัญชี Discord ที่ OAuth ส่งกลับมา
Require Email Verified
ต้องยืนยัน email แล้วเท่านั้น
Require Connections
ต้องมีบัญชีเชื่อมต่อขั้นต่ำตามจำนวนที่ตั้งไว้
ใส่ country code คั่นด้วย comma เช่น TH,US,JP

🛡️ Anti-Alt / IP Security

ตั้งค่าการตรวจ IP ซ้ำ, device ซ้ำ, IP เคยโดนบล็อก, header spoof และ lookup failure ต่อเซิร์ฟเวอร์
Hardening
เปิดระบบ Anti-Alt
ถ้าปิด ระบบจะไม่ใช้กฎ IP ซ้ำ, Device ซ้ำ, IP เคยโดนบล็อก, Header น่าสงสัย และ Lookup failed ในหมวดนี้
Block Hosting / Datacenter
บล็อกเครือข่าย hosting/datacenter เมื่อ lookup ตรวจพบ
การตั้งค่าเข้มเกินไปอาจทำให้ผู้ใช้ปกติยืนยันช้าหรือไม่ผ่าน โดยเฉพาะเครือข่ายโรงเรียน หอพัก ร้านเกม หรือเน็ตมือถือที่แชร์ IP

Policy Notes

อธิบายเงื่อนไขที่ระบบจะใช้ประเมินสมาชิกตอนยืนยันตัวตน
🌐 Network Risk IP / ASN / ISP
ระบบสามารถแสดง raw IP, ประเทศ, เมือง, ISP, ASN, VPN, Proxy, TOR, Hosting ตามข้อมูลที่เก็บและถอดรหัสได้
👤 Account Risk Discord Profile
ตรวจอายุบัญชี, email, email verified, locale, flags, connections และ guild summary เท่าที่ OAuth ให้มา
🎭 Role Assignment Permission
ก่อนส่งแผงควร validate ว่าบอทมียศสูงกว่า role เป้าหมาย และ role ไม่ใช่ managed role
⚠️ Sensitive Data Raw IP
รายการทั่วไปจะแสดงข้อมูลสรุปเพื่อให้อ่านเร็ว ส่วนเจ้าของบอทกดดู Member Detail เพื่อเปิดข้อมูลเต็มที่ระบบเก็บและถอดรหัสได้ พร้อมบันทึก audit ภายในทุกครั้ง

Data & Privacy

อธิบายข้อมูลที่ระบบแสดงและขอบเขตการใช้งานใน Dashboard นี้
Sensitive
🌐 Raw IP แสดงในหน้าแอดมิน
ระบบจะแสดง IP จริงใน Member Detail เมื่อ backend มีข้อมูลและถอดรหัสได้ โดยคำขอเป็น Owner-only, ใช้ CSRF และต้องบันทึก audit สำเร็จก่อนส่งข้อมูลกลับ
👤 Discord Account OAuth Data
แสดงข้อมูลบัญชี เช่น user id, username, global name, email, email verified, locale, flags, connections และ guild summary เท่าที่ระบบเก็บไว้
📱 Device / Browser Client Summary
แสดงข้อมูล browser, OS, timezone, language, screen, viewport และข้อมูลอุปกรณ์อื่น ๆ ที่ callback ส่งมา
🎭 Role / Member Guild Context
แสดงผลการให้ยศ, role assignment result, nickname, joinedAt และ member roles ตามข้อมูลที่มี

สิ่งที่ยังพักไว้ก่อน

ไม่ทำในรอบนี้ เพื่อไม่ให้ scope บานและไม่ชนกับ Log Center ที่พักไว้
📜 Log Center เต็ม Later
Admin action logs, role assignment logs, data deletion logs, advanced filters และ audit center เต็มยังพักไว้
🗑️ Data Deletion เต็ม Later
รอบนี้ยังไม่ขยายระบบลบข้อมูลทั้งชุด เพราะควรทำหลังมี Log/Audit Center ที่ตามรอยได้ก่อน
🧰 Env Checker เต็ม Later
Security Center/Env Checker แบบเต็มพักไว้ก่อน แต่ validation panel จะตรวจ env ที่จำเป็นต่อ verification เท่าที่ทำได้
หน้านี้คือ Owner Verification Admin Center ใน runtime เดียว edit existing panel และ callback hardening
