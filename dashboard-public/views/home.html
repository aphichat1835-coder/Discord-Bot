🛡️ Discord + Security Dashboard

จัดการระบบยืนยันตัวตน Discord แบบครบในหน้าเดียว

Dashboard สำหรับแอดมินเซิร์ฟเวอร์ ใช้ตั้งค่าแผงยืนยันตัวตน OAuth2, ตรวจสอบข้อมูลสมาชิกที่ยืนยันแล้ว, ดูสรุปความเสี่ยง และจัดการแผงยืนยันเดิมใน Discord โดยไม่ต้องลบแผงเก่าทิ้ง

🚀 เข้าสู่ระบบด้วย Discord ดูความสามารถ
ต้องเป็น Owner หรือมีสิทธิ์ Administrator / Manage Guild ในเซิร์ฟเวอร์นั้น จึงจะเห็นและจัดการ Dashboard ของเซิร์ฟเวอร์ได้

ดูสถานะระบบ, policy, สมาชิกที่ยืนยันแล้ว, risk summary และข้อมูลที่ระบบเก็บได้
🛡️ Security Checks validate ก่อนส่ง
ตรวจ role hierarchy, managed role, bot permission, channel permission และ env ที่จำเป็น
