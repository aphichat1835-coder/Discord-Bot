Delete Data Guild Admin ลบได้เฉพาะ log ของ guild นี้
Global Identity Owner-only

Danger Zone

การกระทำที่เกี่ยวกับข้อมูลควรทำอย่างระวัง
ปุ่มลบในหน้า Members จะ soft-delete เฉพาะ VerifyLog ของสมาชิกคนนั้นในเซิร์ฟเวอร์นี้ ไม่ลบระบบอื่นและไม่ลบ global identity โดยตรง
ถ้าต้องการลบข้อมูลลึกระดับ OAuthUser / IpIdentityLink / cross-guild identity ควรทำผ่าน Owner Dashboard เท่านั้นใน phase ถัดไป
